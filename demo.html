Ce que voit le restaurateur, ce que vous intégrez

Cette page présente le résultat visible côté restaurateur. Pour un éditeur de caisse, l'ensemble de ce calcul — classification, food cost, seuils de rentabilité — est exposé par une API dédiée, à connecter directement à vos données de vente existantes.

Les prix matière première (le « cours du jour ») sont synchronisés chaque nuit depuis des sources de mercuriale professionnelle, sans ressaisie côté restaurant.
